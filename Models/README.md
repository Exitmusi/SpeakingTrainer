# Local English speech model

`vosk-model-small-en-us-0.15` was downloaded unmodified from:
https://alphacephei.com/vosk/models/vosk-model-small-en-us-0.15.zip

The official model catalog lists this model under Apache-2.0:
https://alphacephei.com/vosk/models

Vosk C# binding: NuGet `Vosk` 0.3.38, Apache-2.0.
https://github.com/alphacep/vosk-api

The application performs no model downloads or cloud recognition at runtime.
Keep this directory next to the executable when distributing the application.
